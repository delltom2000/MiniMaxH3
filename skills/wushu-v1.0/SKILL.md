# wushu-v1.0

把“激烈、电影感、真功夫”落实成可见动作及其后果。优先实现用户已确认的人物、时长、画幅、武器、场景和对白。把本技能作为武术编导层；由视频模型技能负责最终格式。

## 读取顺序

- 每次编排先读 [攻防与镜头规则](references/choreography-camera.md)。
- 涉及长枪、刀剑、棍或徒手时读 [兵器与距离](references/weapons-distance.md)；未知兵器先确定长度、握位、攻击端和可达范围，不能套用长枪握法。
- 需要加强已有提示词或给出导演指令时读 [编导强化提示词](references/director-prompts.md)。
- 需要五段一分钟、12秒示例、H3 接入或问题修正时读 [示例与纠错](references/examples.md)。
- 用户调用 H3 时同时使用 h3-prompt-writing，读取其对应模式指南；保持技能规定的字段、标签、台词格式和时码。没有该技能时按示例中的模式接口输出，并说明这是提示词而非已经生成的视频。

## 默认与范围

1. 使用影视编排，不把本技能表述成某门派认证、实战验证或已提取全部电影动作的数据库。
2. 优先采用人物武器对应的身体机制。用户要真武术时保持落地重心、真实射程和接触关系；用户明确要玄幻时才增加轻功、悬空或法术，并仍保留攻防因果。
3. 保留参考人物脸、发型、衣服、体型与画幅。只用人物卡的身份信息时，不沿用错误握位或摆拍站姿。
4. 沿用用户的声音要求。本项目默认无背景音乐，以同步兵器声、脚步、衣料、破坏和呼吸组织节奏；不要自行添加音乐、枪炮或夸张爆炸声。
5. 没有指定时长时可采用12秒一段。用户给定5×12秒时严格输出60秒；“五镜头”若同时要求切镜，则解释为五个生成段落，段内允许切镜。若明确要求五个连续长镜头，则遵守连续拍摄。
6. 不为小空缺反复追问；明确标出必要假设并继续。缺少指定附件时不可声称已参考其脸或姿势。

## 编排流程

### 1. 建立空间与状态

写明人物A/B的起始左右位置、面向、间距、武器长度与握位、摄影机所在侧、可走路线和障碍。列出场景固定地标与真实可进退空地。为每段记录开始/结束状态：人物位置、朝向、枪尖方向、衣损、道具破损、受压方与台词。

把“射程”当作动态关系：前手位置、滑杆、臂伸、腰转和踏步共同改变可达范围。不要把两杆枪的长度相加当作身体间距，更不要把四米距离写成轻松贴身互捅。

### 2. 先写双方动作，再设计镜头

为每个交锋写完整链条：

`发动者/目标线 → 应招者防线与步法 → 实际偏离或接触 → 借机反攻 → 新距离/位置`

为守方安排与来招相容的防守或承受后果。不能一人连续表演、另一人拿武器发呆；也不能双方同时命中而没有伤害、闪避或兵器阻挡。每次环境破坏都须有明确落空路径、接触点和回收动作。

### 3. 检查持械与发力

把握位和发力写成可拍细节：后手/前手位置、是否滑动、支撑脚、腰肩方向、武器运动线、收回路线。区分枪尖突刺、棍身横扫、刀刃劈切、剑尖刺线；不能把所有兵器写成转棍。

长枪采用用户已给出的基准：后手尽根、前手如管、半马中平、小圈拦拿、蹬转长扎。具体参数参照兵器文件。近身变化若必要，只作短暂险境并给出退出或握法转变的因果。

### 4. 按真实播放时间安排动作密度

先分配对白、交锋、跳跃、险招强调和收束，再填攻击。密集短扎可按每秒约3次明确攻击编排；该数值是本项目的影视节拍目标，不是所有动作或武术的生理常数。大幅挥击、跳跃、重击不得强塞同样密度。

把格挡与攻击并行，不用“攻击+格挡”虚增攻击次数；一组三枪必须分别写明目标或线路。区分真实攻击、虚点与防守。按“起动—威胁—应招—回收”检查是否能在给定时段表现。若过载，简化花招或减少切镜，保留关键攻防。

### 5. 让镜头揭示危险和空间

在出枪者单人、应枪者单人、险招细节、脚腰握位与完整交锋之间切换。激烈连招、跳跃轨迹和换位用全景证明；近景用画外来枪建立对手存在。单人镜头不能把战斗暂停成表情展示。

沿用动作方向和目光轴线；换位通过连续全景或明确中性机位交代。优先用短推、横移、后撤领拍、受控甩镜与升降服务动作；不要将“大师级”翻译成随机抖动、反复绕圈或全片固定双人中景。

### 6. 使用快慢对照与物理声音

快动作占主体。慢动作只强调一件危险事件，如枪尖擦衣、逼近导向手或集中击中旧裂纹；一般每段0–1处、约0.25–0.6秒播放时间，全部计入总时长，随后立刻恢复快打。不回放同一枪制造攻击密度。

区分“摄影机缓慢推进”和“演员慢动作”。金属头擦杆、木杆撞击、鞋底踏地、局部石竹破裂分别配不同声音；不要每次碰枪都响成炮击。

### 7. 转成模型提示词

输出每段独立可复制的完整块，把必要身份、起始状态、握法、节奏、声音写入本段，不依赖“同上”。保持同一参考图编号和角色音色编号。中文解释与模型规定的英文提示词分开；对白保留原语言。

H3 Ref2VA 使用六段顺序：`subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music`。首镜无时码，后续切镜写 `[Shot N] At MM:SS.mmm,`。最后一镜动作延续至段末。无配乐写 `N/A`。

## 输出与复核

完整剧本交付：
1. 简短共用设定与参考映射。
2. 每段起止状态、段内时码、双方攻防、镜头/运镜、同步声音。
3. 每段可复制提示词；需要中英对照时提供两层。
4. 总时长与连续性检查结果。

仅“加强提示词”时，直接给修订后的完整提示词和必要假设；无需再输出冗长分析。用户要固定武器时不擅自改剧本、人物或兵器。

交付前逐项检查：
- 时段是否连续、无重叠/空档；慢动作是否计入总长；中文台词是否有说完的时间。
- 所有来招是否有对应应招或受击结果；交锋是否真实改变枪线、空间或主动权。
- 握位、武器长度和滑手是否合理；全景是否能看清脚与完整武器。
- 从单人切回全景是否同一动作而非回放；左右交换是否已展示。
- 跳跃是否改变攻防线，是否有完整起落；是否有无故转圈、悬空、穿模。
- 环境破坏是否局部、可追溯；损坏与衣裂是否延续。
- 音效是否对应具体接触，是否遵守无背景音乐。

把检查局限说明为“提示词结构已检查”；没有生成/观看视频时，不声称成片已经流畅或武术动作已经验证。
