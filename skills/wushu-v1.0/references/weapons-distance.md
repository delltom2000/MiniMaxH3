# 兵器与距离

以下是影视编排基准。长枪部分来自本项目用户提供的“持枪、拦拿扎、六合枪”口诀；不将一套握法宣称为所有流派的唯一标准。

## 长枪：尽根、放长、小圈、直扎

### 持枪与回收

- 使用约2.8–2.9米枪时，让右后手掌心抵住最末端，后手后面没有明显长尾；左前手在前方约55–70厘米处环握导向，虎口朝下。反手持枪人物可整体镜像，须始终一致。
- 预备与拦拿时后把贴右肋下，半马步侧身，沉肩坠肘、头正项直；枪尖中平对敌。后肘与枪尖方向相关，不把握把架在胸前举成横杠。
- 长扎时后腿蹬、腰转、肩顺、后把沿枪轴前送；前手相对枪杆向后滑，扎尽时接近后手。后手仍握原来的枪根，不重新抓到枪杆中央。
- 收枪沿原路回来，前手再前滑恢复导向，把端回肋下。把贴肋是起势/拦拿依托，不表示把端在充分扎出时被固定在肋上。
- 让握根、导向、滑手至少在一个斜侧中景或全景内看清。插入手部镜头时仍须保持左右方向与正在发生的同一枪。

### 拦拿扎

用后腕和腰带小圈，让前手提压导向，把真正来枪偏离有效目标线，紧接着直扎。“拦—拿—扎”可以变换组合；不要每次把完整三字做成三次僵硬停顿。

本项目小圈枪尖摆幅可用约20–30厘米作视觉基准；随来枪角度调整，不用大幅绕头舞花。连续缠拿必须马上形成出枪机会，不能双方长期原地搅杆。

可写“来枪逼前手→收滑导向手并小圈拿开→后腿蹬转贴杆长扎→对手外拨撤脚”。把前手威胁用于视觉险招时保留实际避让，不把锋刃穿过手指。

### 射程与距离

对2.8–2.9米枪，本项目双人身体中心主要相距约3.8–4.5米；踏步伸臂攻击中可短暂压至约3.0–3.4米，守方撤步或侧跃恢复间距。这是布景编排参数，不是通用安全距离或所有枪术的固定数值。

从前手到枪尖保留约两米明显投影；把足步、腰肩、臂伸与滑杆对可达范围的贡献写清。两人武器可以在远处相交，身体不用靠到肩碰肩。镜头不能用长焦压缩把广阔交锋拍成贴身角力。

接近至短兵距离须有动因，如来枪被压偏后一方短暂抢入；随后写明守方退/换线或改变持法。一般长枪对长枪，不以枪尾顶腹、杆身反复撞胸取代枪尖威胁。

### 跳跃与破坏

- 后跃约0.8–1.2米：脱离逼近枪尖，枪尖仍指敌，落地立即拿扎。
- 侧跃约0.6–0.9米：改变攻击线，落地就反攻；不绕贴身体穿过。
- 前跃约0.7米、离地约0.3–0.5米：借步或低阶进枪，落地蹬转时直扎/斜扎。空中不后翻，不横举转枪。
- 刺偏至旧桌边：枪尖集中入旧裂纹，局部崩角，杆震，沿原线抽回。不要一根普通长枪无因炸碎整张厚石桌。
- 竹篱受击：守方真实侧闪，枪尖穿入老旧薄竹，局部断条；保留落空路线与下次回收。

## 刀、剑、棍、徒手的迁移

| 类别 | 核心视觉 | 距离和握位 | 常见错误 |
|---|---|---|---|
| 单刀 | 刃口劈切与带身步的防守反击 | 握柄；按刃长、伸臂及踏步给有效距离 | 把刀抓在刀身中央；隔空劈到敌人；翻腕后刃向错 |
| 剑 | 剑尖刺线、刃向、回收与侧身 | 握柄；短刺和步进长刺分开 | 当重棍抡；平面挥花而剑尖从未威胁对手 |
| 棍 | 棍身/两端可用，摆动与直点结合 | 依长度和打法写清握距及调整 | 把枪的尽根直扎规则套给所有棍法；手突然换端 |
| 徒手 | 身体重心、拳腿可达范围、接触反应 | 根据直拳、步进、踢击、缠斗分别设距 | 两人隔太远假打；无格挡却毫发无伤；打击者停住等应招 |

需要短兵/徒手时，从当前器械撤出、丢失或贴身的实际过程过渡；先确认用户允许该变化。对重兵器按运动幅度分配时间，不给大劈砸强加每秒三次满力攻击。

## 把抽象词换成画面

| 抽象表达 | 可执行表达 |
|---|---|
| 枪很重、力量很大 | 后腿蹬地→腰转送把→前手滑回→枪尖逼敌撤步；落空点扎旧桌边短裂 |
| 速度极快 | 一秒内扎前手、扎中线、短收再扎，守方每次小圈偏线并撤脚 |
| 生死凶险 | 枪尖逼导向手，守方滑手拿开；虚点后变线擦裂衣边，身体已经侧让 |
| 霸气压阵 | 连续夺回中线，封侧移路线，让对手只能外拨退步；保持长距离 |
| 真武术 | 具体握位、发力链、点/刃方向、来招应招、落地重心和回收路线 |
