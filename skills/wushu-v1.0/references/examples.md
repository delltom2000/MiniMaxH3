# 示例与纠错

## 一分钟长枪剧情结构

按5个生成单元、每段12秒组织，段内允许切镜。使用同一人物和场景参考，以下只是可替换的结构示例，不固定为每次任务的剧情。

| 全片时间 | 本段主动权变化 | 镜头组织 | 连续状态 |
|---|---|---|---|
| 00–12秒 | 对峙起枪→女方抢中线 | 男方握根单人→女方单人→拉远三连交锋→避锋近景→全景 | 女左男右；桌边小角崩落 |
| 12–24秒 | 圈拿绕场→前手险失→反扎 | 后腕细节→侧跃单人→连续换位全景→前手险距→快攻 | 男左女右；桌损保留 |
| 24–36秒 | 男方抢三连→擦衣→女方反攻 | 男攻单人→女防单人→九枪全景→衣边险招→落地长扎换位 | 女左男右；衣边小裂 |
| 36–48秒 | 跃退脱线→跃进落地扎→再逼退 | 双方分别起动/避线→全景起落→桌边接触→全景换位 | 男左女右；桌边裂、衣裂保留 |
| 48–60秒 | 密集抢扎→脱身被截→中线受压 | 男方眼神→女方拿扎→十二攻全景→逃路单人→全景截线→男近脸 | 男左女右；竹条局部断；对手仍抵抗 |

慢动作可置于第2段7.20–7.55、第3段5.00–5.35、第4段3.70–4.25，均为段内播放时间，总计1.25秒，包含在60秒内。需要其他节奏时调整，不照抄这个固定配置。

## 12秒不同兵器示例：双人刀剑

设定：石阶前空地，A单刀在左朝右，B剑在右朝左，两人约2米；兵器长度和踏步决定威胁距离，不能套长枪的四米间距。

| 段内时间 | 攻防 | 镜头 |
|---|---|---|
| 0.00–1.50 | A进步斜劈，B侧撤抬剑偏开，马上送回短刺 | 50mm A斜侧单人，剑从画外接入；随进步横移 |
| 1.50–3.20 | A侧身让刺，刀刃回到来剑线，逼B撤前脚；B收剑再进 | 50mm B全身单人，刀从左画外威胁脚前；随撤步后退 |
| 3.20–6.80 | B步进直刺→A偏线反劈→B格开斜退；A再进，B换线反刺 | 28mm连续全景，看兵器可达范围、脚步与站位变化 |
| 6.80–7.15 | B来剑擦开A肩侧衣边，A身体已让开 | 85mm衣边和剑尖细节，0.35秒慢动作，无受伤 |
| 7.15–10.20 | 恢复快打，A斜侧跃落地追劈，B斜撤反刺，A偏线拦回 | 28mm后撤领拍，完整看起落，来招与应招不断 |
| 10.20–12.00 | B被逼近低阶，短收再刺；A接住来线继续逼进 | 65mm B单人脸肩，来刀从画外逼近；微推，保留呼吸和碰擦 |

这段示例不把“三枪每秒”机械套给大刀劈击，也不让刀剑按枪的前手滑杆规则持握。

## H3 接入接口

模型字段规范由 h3-prompt-writing 技能决定；读取当前指南，不臆测生成API或声称已运行模型。

### Ref2VA

按以下顺序输出，每段都是完整块：
- subject_definitions：用实际给定参考定义角色、道具与场景；Picture编号不漂移。
- summary：用[reference generation]开头的英文概括。
- retention_analysis：为已定义Subject写可见镜头和保留关系；新衣损是剧情状态变化。
- detailed_description：英文风格开头；[Shot 1]无时间，后续[Shot N] At MM:SS.mmm；注明起止位置、握法、攻防、运镜、接触声。
- overall_soundscape：真实环境与同步物理声。
- non_diegetic_music：无配乐为N/A。

中文对白放入<d>[Chinese] ...</d>，同一说话者沿用全片声源编号。句子跨切镜时采用H3指南的跨镜标记；不要在声音段重复完整对白。

### 文本与关键帧模式

使用 integrated_multimodal_description、overall_soundscape、non_diegetic_music，具体首末帧与格式按对应指南。没有真实参考图时使用文本模式，不制造不存在的Picture来源；需要指定第一帧/末帧时把兵器方向、握位与相邻段状态写进关键帧条件。

## 纠错示例

**弱：**两人握枪杆中部，近距离互抡，女主枪尾顶腹，男方原地架枪，固定双人中景四秒。

**强：**后手尽根、前手导向，约四米起距。女主蹬转直扎，前手滑回；男方小圈拿开同时斜撤，短收反扎前手。女主侧跃避线，落地贴杆长扎。先用女主斜侧单人看到送把滑手，切男方避锋，立即拉远拍完整起落、枪距和反攻。

**弱：**电影大师级运镜，攻击非常迅速，声音震撼。

**强：**28mm全景沿南侧横移，拍清一秒三次不同线的扎与应招；下一来枪切85mm受压者脸肩，枪尖从左画外掠近，轻摇跟侧身；随反扎切回24mm后撤领拍。每次擦杆有短敲/擦声，鞋底与落地同步，不加炮击式重音。
