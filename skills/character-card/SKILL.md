# 人物卡 character-card

## 默认预设

采用 [四视图预设](references/default-preset.yaml) 和 [生成与改款模板](references/prompt-patterns.md)。默认横幅16:9，左侧约36%为面部至肩胸的大特写，右侧三栏依次正面、严格90度侧面（朝画面右侧）、180度背面全身。白色或浅灰摄影棚，柔和三点布光，无文字、无水印。三个全身人物同尺度、同头顶线和脚底线，从头发到鞋底完整入画。

把这个预设作为角色卡任务的默认；用户的本次要求优先。人物卡之外的任务不套用本布局。只有实际写入项目配置后才说项目默认已更新。

## 读取参考并锁定角色

1. 先查看实际可用的参考图；本地图片用 view_image。没有看到图片时不能声称已参考，要求重新附图；仍可建立文字设定。
2. 区分人物参考、服装参考、布局参考。布局样图仅约束排版，不自动把其中人物或衣服复制给新角色。
3. 记录脸部身份锚点：脸轮廓、颧骨、下颌、眉眼间距、鼻形、唇形、肤色、发际线、发型、年龄感、独特标记。保留个性，避免统一网红脸；不主动变年轻或换种族。
4. 记录身材锚点：头身比、肩腰胯关系、躯干长度、腿长、大小腿比例、膝位、腿部轮廓和体态。保持协调自然，不用拉伸腰腿或缩小头部制造长腿。仅在用户要求时调整体型。
5. 记录服装结构：层次、领口、袖长、剪裁、材质、配色、开合件、鞋袜与配饰。看不到的背面结构采用保守合理推断，并简短注明；不得声称是原图真实细节。

## 生成四视图

使用可用的图像生成/编辑工具直接生成图像；不以提示词冒充成图。优先遵守该工具的参考输入与技能规则。所有本地目标路径都存在时使用 referenced_image_paths；否则用能包含全部参考的最小 num_last_images_to_include；两种机制不能混用。

在一次请求里明确四栏是同一个人、同一套衣服、同一发型和同一身体比例。正背面双脚自然平行，手臂放松且不遮挡衣服，侧面自然站直；不把侧面拍成四分之三视角。面部特写自然微笑或用户指定表情，三张全身保持放松稳定。真实摄影风、清晰皮肤和布料质感；不承诺工具未实际提供的8K分辨率。

不擅自加logo或文字。用户要求保留已有标识时按其要求执行。默认不添加武器；已有道具保留时安排不遮身体与服装的站位。

## 支持单独改款

区分修改对象：
- “换一套衣服”：保留人物身份与体型，四栏同步换同一套衣服。
- “只改裙子/鞋袜/上衣/颜色”：只修改指定款式，并同步更新每个能看到它的视图。面部、发型、身体和其他衣物不变。
- “只改背面设计”：只改变背面可见设计，侧面必要的交界细节同步；不改变正面已有造型。
- “只改某一张图/某一个视角”：仅编辑该栏，其余栏保持；若因此四栏服装不再一致，说明这是局部方案，不声称完整一致定稿。
- “单独输出侧面”：从已确认角色卡派生单视图，沿用身份、比例、衣服与灯光。

使用当前角色卡作为编辑目标，原始人物图作为身份补充。不要无故重新造人。修改前锁定未变项，修改后检查目标改动与意外漂移。

## 检查与交付

逐项检查四张脸和发型能否对应；肩腰胯、腿长膝位、鞋袜高度是否一致；面料、接缝、拉链、配件在三个角度是否连贯；侧面和背面是否真实转向；手指、脚和四肢是否完整；全身是否裁脚、遮腿、变尺度。发现明显错误则针对错误编辑重试；没有检查生成结果时不能宣称一致性已验证。

返回生成图与必要的简短说明。图像工具返回的图片按工具规定直接展示；不要为了保存自动保存的生成图而重建文件。需要另行文件交付时遵守保存规则。
